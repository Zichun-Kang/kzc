物理海洋学 · 从流体力学出发

风为什么不能把海水
一直顺风推？

艾克曼理论把你熟悉的黏性剪切流，放到了一个旋转的地球上。只加上这一点，流速就会随深度转向，整层水甚至会向风的侧面输运。

01 / 先建立物理图像它是一种旋转流体边界层

想象风持续向东吹过一片深海。风通过海面风应力向水输入水平动量，湍流混合再把动量向下传递。与此同时，地球自转使运动的海水受到科里奥利加速度。艾克曼理论研究的，就是这两种作用如何形成一个稳定的垂向流速结构。

你已经熟悉：剪切传递动量

牛顿流体中，剪应力为 μ ∂u/∂z。海洋中的大部分垂向动量交换来自湍流，因此用一个有效的运动黏性系数 Av 表示混合：

τxz = ρ Av ∂u/∂z

Av 的单位是 m²/s；它是湍流闭合参数，不是海水的分子运动黏度。

新增一项：旋转参考系

在地球参考系，水平科里奥利加速度为：

aC = −f k × u
f = 2Ω sinφ

k 向上，φ 为纬度，Ω ≈ 7.292 × 10−5 s−1。北半球 f > 0，加速度指向流速右侧；南半球相反。它垂直于流速，本身不做功。

刚开始吹风时，海水会加速；这里主要讨论风持续作用后形成的稳态。此时不是“风让水一直加速”，而是每一深度的科里奥利力与湍流应力的垂向散度相平衡。

不要把混合理解成“上层拖下层，每层固定转一个角度”。真正决定流速的是连续的动量方程；下面的螺旋是它的解。

02 / 从动量方程走到边界层只保留主导的两项

取 x 向东、y 向北、z 向上，海面 z = 0，水下 z < 0。u、v 分别为东西和南北流速。忽略水平黏性后，水平动量方程写成：

Du/Dt − fv = −(1/ρ) ∂p/∂x + ∂(Av ∂u/∂z)/∂z
Dv/Dt + fu = −(1/ρ) ∂p/∂y + ∂(Av ∂v/∂z)/∂z

经典表层艾克曼模型作如下简化：

  • 稳态、水平一致：局地随时间变化和非线性平流均可忽略；只求随 z 变化的流速。
  • 局地 f 平面：把 f 看作常数，且远离赤道；密度 ρ 取常数。
  • 恒定混合：Av 不随深度变化。
  • 足够深：表层受风影响的边界层不接触海底。

真实海洋通常还存在水平压力梯度。其对应的地转流是压力梯度力与科里奥利力平衡的背景流，满足 −fvg = −px/ρ、fug = −py/ρ。下面忽略压力梯度，或等价地在边界层内背景地转流近似不随深度变化时，讨论从总流中减去它后的艾克曼流 uE、vE。

−f vE = Av uE″
f uE = Av vE″
撇号表示对 z 求导；两边单位都是加速度 m/s²。

为什么右边是二阶导数？因为单位质量的净剪切力是 (1/ρ)∂τ/∂z，而应力本身与一阶速度梯度成正比。对一个薄水层，上下界面应力的差才决定它的净受力。

还需要边界条件

ρ Av uE′(0) = τx，　ρ Av vE′(0) = τy
uE, vE → 0　当 z → −∞

这里 τ = (τx, τy) 指空气施加给海水的应力，单位为 N/m²。深处趋零的是艾克曼流，不一定是总海流。

03 / 解长什么样？越深越弱，同时不断转向

先令风应力向东，即 τx = τ > 0、τy = 0。定义衰减尺度 δ、半球符号 s 和海表流速大小 U0：

δ = √(2Av/|f|)，　s = sign(f)
U0 = τ / [ρ √(Av|f|)]

uE(z) = U0 ez/δ cos(z/δ − π/4)
vE(z) = s U0 ez/δ sin(z/δ − π/4)

指数因子使速度向下衰减，三角函数使方向向下旋转。在北半球，海表流速指向东南，位于风应力右侧 45°；随深度增加，从上方俯视，流向顺时针旋转。南半球则镜像反转。

展开数学推导：用一个复数把两条方程合并

定义 W = uE + i vE，其中 i² = −1。这只是把水平向量的两个分量装进一个记号，不增加任何物理假设。

Av W″ = ifW
W = C exp[(1 + is)z/δ]
C = τδ / [ρAv(1 + is)] = U0 exp(−isπ/4)

特征根是 ±(1 + is)/δ。由于 z 向深处趋于负无穷，只保留实部为正的根，另一项会向下发散。再代入海表应力条件 ρAvW′(0) = τ，就得到 C；取实部和虚部即得上式。

亲手调整：混合强度会改变什么？

试着增大 Av：动量被分配到更厚的水层，δ 增大，海表速度 U0 反而减小；但整层输运不变。左图的归一化螺旋形状也不变，变化体现在实际速度和深度尺度上。

δ 是速度降到海表值 1/e ≈ 37% 时的深度，不是硬边界。在 3δ 处还剩约 5%。有些教材把 DE = πδ 定义为“艾克曼深度”，此处流向相对海表转过 180°、速度剩约 4.3%。比较“厚度”前，要先确认定义。

04 / 比螺旋更稳健的结论整层水向风的侧面输运

单层流速回答“这一深度的水往哪里走”；输运回答“把各深度的流速向量累加，净搬走多少水”。定义单位水平宽度的体积输运：

Mx = ∫−∞0 uE dz，　My = ∫−∞0 vE dz
单位 m²/s：速度 m/s 乘上深度 m。若再乘垂直于输运方向的截面宽度，才得到 m³/s。

不用积分复杂的螺旋解，直接对动量方程沿深度积分，并用深处剪切应力趋零的条件：

−f My = Av[uE′(0) − uE′(−∞)] = τx/ρ
f Mx = Av[vE′(0) − vE′(−∞)] = τy/ρ
ME = (τy, −τx)/(ρf) = (τ × k)/(ρf)

北半球净输运在风应力右侧 90°；南半球在左侧 90°。整层内部相邻水层之间的剪切力相互抵消，只剩海面的外加风应力，与整层科里奥利力平衡。

由此也能看出：只要稳态、可忽略平流、深层应力为零等条件仍成立，即便 Av 随深度改变，详细螺旋不再是上面的形状，输运关系仍可成立。MIT 的教学推导采用的是质量输运，等于这里的 ρME，因此公式中不含 ρ。

比较对象北半球向东风应力下适用条件
海表艾克曼流速向东南，偏右 45°经典恒定 Aᵥ、无限深模型
整层艾克曼输运正南，偏右 90°满足整层动量平衡及应力边界条件
实测海表总流速不必是 45°还包含背景流、潮流和非稳态响应等

一个数量级例子

取 f = 10−4 s−1、ρ = 1025 kg/m³、Av = 0.01 m²/s，向东风应力 τ = 0.10 N/m²。则 δ ≈ 14.1 m，U0 ≈ 0.098 m/s，而 |ME| ≈ 0.976 m²/s、向南。若输运沿一段 100 km 宽的东西向截面均匀分布，体积流量约为 9.76 × 104 m³/s，即 0.098 Sv（1 Sv = 106 m³/s）。

05 / 连续性方程接上最后一环水平搬走的水，由谁补上？

均匀的风应力在恒定 f 的无限海域产生均匀的艾克曼输运，本身并不会产生内部上升流。只有当输运在水平方向上出现辐散，或在海岸边受约束时，才需要垂向补偿。

开阔海洋：输运的辐散与辐合

让风应力在远大于边界层厚度的水平尺度上缓慢变化，把局地艾克曼解用于各处。对不可压缩连续性方程积分，取边界层底部 z = −H，并近似海表 w(0) = 0：

∂u/∂x + ∂v/∂y + ∂w/∂z = 0
∇h · ME + w(0) − w(−H) = 0
wE ≡ w(−H) = ∇h · ME

这里 z 和 w 均以向上为正，H 取足够深以包含表层艾克曼流；背景流的水平散度暂忽略。于是：

辐散 → 上升

上层向外运走的水多于运入的水，底部必须向上补水：wE > 0。

辐合 → 下沉

上层净汇入的水必须从底部向下排出：wE < 0。

将输运公式代入，得到通常所说的艾克曼抽吸速度：

wE = ∂[τy/(ρf)]/∂x − ∂[τx/(ρf)]/∂y
若 ρ、f 为常数：
wE = (1/ρf)(∂τy/∂x − ∂τx/∂y) = (∇ × τ)z/(ρf)

括号里的量就是风应力的垂向旋度。北半球正旋度对应上升，负旋度对应下沉；若 f 随纬度变化，必须保留上面含 1/f 的完整导数。英文资料常把下沉称为 pumping、上升称为 suction，也常将两者统称为 Ekman pumping；判断方向时以 w 的正负和坐标定义为准。华盛顿大学教学材料也从输运辐散与辐合解释这一过程。

沿岸：即使风近似均匀，也可能上升

想象北半球一条南北向海岸，陆地在东、海洋在西。风应力向南时，右侧输运指向西，也就是离岸；近岸表层失去的水由较深处补给，产生沿岸上升流。风应力向北时，输运向东、指向岸，形成水体堆积和下沉趋势。

沿岸上升流的关键是海岸边界使输运无法在陆地一侧延续。开阔海域“均匀风不产生抽吸”的结论，不能直接套到海岸上。

06 / 知道理论何时会失效记住平衡，也记住假设

  • 赤道附近：f → 0，公式出现发散，意味着这个近似失效，并不表示真实海流无限大。
  • 风快速变化：必须保留时间导数，可能出现惯性振荡。惯性周期为 2π/|f|；稳态是否合适，取决于风的变化和调整时间。
  • 真实湍流和层结：Av 往往随深度、时间变化，密度层结会抑制混合；经典 45° 和规则螺旋不必出现。
  • 浅水与海底：表层和底部边界层可能重叠，底应力不能忽略；净输运应由上下边界应力之差决定。
  • 强平流或复杂海况：锋面、波浪、潮汐等会引入额外动力过程。实测流速不能直接等同于这里的艾克曼流速。

海底也有艾克曼层：内部流动接近固体海底时被摩擦减速，导致压力梯度力与科里奥利力的平衡被打破，出现跨越背景流向的运动。但那里的边界条件是海底无滑移与上方匹配内部流，不能照搬表层的“相对风向 45°”。

用三道问题检查理解

1. 风应力加倍，其他参数不变，会发生什么？

各深度艾克曼流速和整层输运均加倍；δ 不变，转向结构不变。

2. Aᵥ 增大到四倍，为什么输运仍不变？

δ 增大到两倍，U0 减小到一半。流动变厚而变慢；在规定的风应力和 f 下，深度积分后的动量平衡没有改变。

3. 海表向风右侧 45° 流动，为什么整层却向右侧 90°？

因为各深度流向不同，要把各层的速度向量按层厚累加，而不是只看表层或平均角度。在经典解中，沿风分量的深度积分相互抵消，横风分量留下净输运。

把整条因果链串起来：风应力输入动量 → 湍流向下传递动量 → 与科里奥利力共同确定垂向流速结构 → 深度积分得到横风输运 → 输运辐散或辐合通过连续性引起上升或下沉。
